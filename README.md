# APC Operations

APC Operations System for Shipping, Transportation, QC, Security, and Production.

## Features

- **Shipping Module**: Bill of Lading, Packing List, Certificate of Origin, Commercial Invoice, Gate Pass, Delivery Order
- **Transportation Module**: Vehicle Master, Driver Master, Transport Order, Weighment, Trip Sheet, Fuel Log
- **QC Module**: Certificate of Analysis, Quality Inspection, Test Results, Product Specifications
- **Security Module**: Gate Entry/Exit, Visitor Pass, Material Movement
- **Production Module**: Production Order, Batch/Lot Master, Production Entry
- **Zoho Integration**: Sync with Zoho Books, Inventory, CRM

## Installation

```bash
bench get-app apc_operations
bench --site [site-name] install-app apc_operations
```
